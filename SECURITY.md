# Security And Privacy

PoseAnalysis is built for local-first analysis of youth sports videos. The repository does not require users to upload videos to a server.

## Privacy Rules

- Do not commit real child videos.
- Do not commit reports containing a child's real name, face screenshots, school, club, address, phone number, or exact training location.
- Use anonymized identifiers such as `athlete`, `A01`, or `child athlete`.
- If screenshots are added for documentation, crop or blur faces and background identifiers.

## Reporting Security Issues

Open a private security advisory on GitHub if the issue exposes local files, secrets, identity data, or unintended video paths.

For ordinary bugs, use GitHub Issues.

## Safety Scope

PoseAnalysis reports are coaching aids, not medical diagnosis, injury diagnosis, or return-to-play clearance.
