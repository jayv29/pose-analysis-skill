# 动作阶段识别规则

## 使用原则

动作阶段识别用于帮助 Codex 从视频和姿态 JSON 中找到应分析的时间段。阶段识别必须以视频画面为主，姿态指标为辅。

如果阶段无法稳定识别，报告应降低评分置信度。

## 花剑-弓步冲刺专项

### 阶段 F1：准备姿势

视觉特征：

- 双脚分立，身体在可启动姿态。
- 剑手和非剑手相对稳定。
- 重心没有明显前移。

关注：

- 重心是否可启动。
- 前后脚距离是否适合当前训练目的。
- 上半身是否提前泄露进攻意图。

### 阶段 F2：启动

视觉特征：

- 持剑臂开始威胁或身体开始前向组织。
- 后腿开始加载或推进。
- 前脚尚未明显跨出或刚开始离地。

关注：

- 剑手是否先于脚步建立威胁。
- 是否出现耸肩、抬头、身体先倒。
- 是否有多余预摆。

### 阶段 F3：推进

视觉特征：

- 前脚向前移动。
- 后腿伸展推动身体。
- 髋部水平向前移动。

关注：

- 后腿是否有效推进。
- 髋部是否随身体平稳前进。
- 前腿是否只是被动跨出。

### 阶段 F4：前脚落地/触达

视觉特征：

- 前脚接触地面。
- 身体制动并接近动作终点。
- 持剑臂接近完成威胁或触达。

关注：

- 前膝轨迹和制动。
- 髋膝踝是否稳定。
- 躯干是否过度前扑。

### 阶段 F5：完成姿势

视觉特征：

- 前腿承重。
- 后腿接近伸展。
- 上肢、躯干和下肢形成终点姿势。

关注：

- 是否稳定、可继续动作。
- 剑手路径是否保持威胁。
- 头、肩、髋是否失衡。

### 阶段 F6：回收与再准备

视觉特征：

- 前脚或后脚回收。
- 重心回到可防守或再进攻位置。

关注：

- 回收速度。
- 是否后撤中丢失平衡。
- 是否能立即接下一动作。

## 花剑-教练课/实战片段

阶段：

1. 距离准备。
2. 刺激或机会出现。
3. 技术选择。
4. 启动与执行。
5. 结果。
6. 回合后调整。

实战片段优先分析得失分前 1-2 秒，不把整段视频平均化。

## 攀岩-连续上攀

### 阶段 C1：观察/准备

- 停在当前位置。
- 头部或身体朝向下一组手脚点。
- 手臂可能保持支撑。

关注：是否在高耗能位置停顿。

### 阶段 C2：脚点建立

- 一脚或双脚重新放置。
- 脚尖、内侧或外侧边缘接触新点。

关注：脚是否一次到位，是否反复试探。

### 阶段 C3：髋部/重心转移

- 髋部朝支撑脚、目标方向或墙面移动。
- 身体张力改变。

关注：是否先用脚和髋组织动作。

### 阶段 C4：手部移动

- 一手离开原点，移动到目标手点。
- 另一手或双脚保持支撑。

关注：手部移动前是否完成脚和髋准备。

### 阶段 C5：稳定/恢复

- 抓到新手点后身体停止摆动。
- 重新建立站位。

关注：是否能稳定，而不是立即用下一步补救。

### 阶段 C6：lead clipping

只在 lead 且画面清楚时分析：

- clip 前站位。
- clip 动作。
- clip 后恢复。

## 攀岩-单个难点动作

阶段：

1. 起始站位。
2. 预加载。
3. 发力/动态移动。
4. 抓点或踩点命中。
5. 控制摆动。
6. 稳定完成。
7. 尝试间调整。

## 基础体能

### 深蹲

阶段：

1. 起始站立。
2. 下蹲离心。
3. 底部控制。
4. 起身向心。
5. 终点站稳。

### 弓步/分腿蹲

阶段：

1. 起始分腿。
2. 下沉。
3. 底部控制。
4. 起身。
5. 换侧或重复。

### 俯卧撑

阶段：

1. 高位支撑。
2. 下放。
3. 底部。
4. 推起。
5. 顶部稳定。

### 平板支撑/hollow hold

阶段：

1. 建立姿势。
2. 稳定保持。
3. 疲劳变化。
4. 结束。

### 跳跃落地

阶段：

1. 起跳准备。
2. 起跳。
3. 空中。
4. 初触地。
5. 缓冲。
6. 稳定。

### 单腿平衡/单腿下蹲准备

阶段：

1. 单腿建立。
2. 稳定保持。
3. 下沉或扰动。
4. 恢复。
5. 换侧。
