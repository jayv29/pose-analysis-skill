# 报告模板

## 通用原则

报告语言为中文，面向教练专业版。所有评分和诊断必须引用视频证据或姿态指标。没有证据时，写明“不足以判断”。

综合评分只在 `可评分` 时输出。`部分可评分` 输出维度观察，不给综合总分。`不可评分` 只给拍摄建议。

生成最终报告前必须读取：

- `final-report-quality.md`
- `phase-recognition.md`
- `knowledge-base/professional-analysis-standard.md`
- 对应项目的 `*-advanced.md`

最终报告要从“报告骨架”升级为“教练可执行复盘”：每个分数有证据，每个问题有阶段，每个建议有复测指标。

## 花剑报告模板

### 花剑-弓步冲刺专项

评分维度：

| 维度 | 权重 |
| --- | ---: |
| 准备姿势与重心预备 | 15 |
| 启动顺序与节奏 | 15 |
| 后腿蹬伸与推进效率 | 20 |
| 前脚落地与前膝控制 | 20 |
| 躯干、髋部和头部稳定 | 15 |
| 持剑臂协调与完成姿势 | 10 |
| 回收与再准备 | 5 |

必须输出：

- 启动是否有多余预摆。
- 后腿是否完成有效蹬伸，而不是只靠前腿跨出。
- 前脚落地时是否稳定，前膝是否明显偏移。
- 弓步完成后躯干是否过度前扑或后仰。
- 回收是否能回到可继续进攻/防守的准备状态。

### 花剑-一对一教练课片段

评分维度：

| 维度 | 权重 |
| --- | ---: |
| 距离控制 | 20 |
| 节奏响应 | 20 |
| 技术动作完成度 | 25 |
| 持剑线与身体协调 | 15 |
| 教练指令执行稳定性 | 10 |
| 回合间调整能力 | 10 |

说明：教练课片段允许更多定性判断，但仍需引用具体时间点。

### 花剑-实战比赛片段

评分维度：

| 维度 | 权重 |
| --- | ---: |
| 距离判断 | 25 |
| 启动时机 | 20 |
| 技术选择 | 20 |
| 脚步与剑手协调 | 15 |
| 防守后再进攻/转换 | 10 |
| 情绪和节奏稳定性 | 10 |

说明：实战片段不应把每个回合都简化为姿态角度。优先判断时机、距离、准备动作和执行稳定性。

## 攀岩报告模板

### 攀岩-top-rope/lead-连续上攀

评分维度：

| 维度 | 权重 |
| --- | ---: |
| 脚法准确性与踩点稳定 | 20 |
| 髋部和重心控制 | 20 |
| 手臂使用效率 | 15 |
| 动作顺序与路线阅读 | 15 |
| 节奏和停顿管理 | 10 |
| 身体张力与摆动控制 | 10 |
| lead clipping 管理 | 10 |

如果是 top rope，`lead clipping 管理` 权重转给 `节奏和停顿管理` 与 `动作顺序`。如果 clipping 不可见，不评分该维度。

必须输出：

- 是否过度依赖手臂拉动。
- 是否能先移动脚和髋，再移动手。
- 髋部是否靠近有效支撑点。
- 是否出现不必要的摆动、反复试探或高耗能停顿。

### 攀岩-单个难点动作

评分维度：

| 维度 | 权重 |
| --- | ---: |
| 起始站位和重心准备 | 20 |
| 发力方向 | 20 |
| 手脚顺序 | 20 |
| 髋部旋转/贴墙策略 | 15 |
| 完成后的稳定 | 15 |
| 尝试间调整 | 10 |

## 基础体能报告模板

### 通用评分维度

| 维度 | 权重 |
| --- | ---: |
| 动作范围 | 15 |
| 关节轨迹 | 20 |
| 躯干和骨盆控制 | 20 |
| 左右对称 | 15 |
| 节奏与离心控制 | 15 |
| 稳定性和重复一致性 | 15 |

### 动作重点

| 模板 | 核心观察 |
| --- | --- |
| 体能-深蹲 | 髋膝踝协同、躯干角度、膝轨迹、深度、底部稳定 |
| 体能-弓步/分腿蹲 | 前膝控制、髋稳定、后脚支撑、左右差异 |
| 体能-俯卧撑 | 肩肘角度、躯干直线、骨盆塌陷、动作幅度 |
| 体能-平板支撑/hollow hold | 肋骨-骨盆位置、腰椎代偿、肩部稳定 |
| 体能-跳跃落地 | 落地缓冲、膝内扣、左右受力、二次弹跳控制 |
| 体能-单腿平衡/单腿下蹲准备 | 骨盆水平、膝轨迹、足踝控制、躯干补偿 |
