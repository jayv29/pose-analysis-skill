# 历史对比规则

## 对比单位

历史对比以动作模板为单位，不以项目整体为单位。

比较键：

```text
匿名运动员ID + 项目 + 动作模板
```

示例：

```text
athlete-a + 花剑 + 弓步冲刺专项
athlete-a + 攀岩 + lead-连续上攀
athlete-a + 体能 + 深蹲
```

## 允许比较

- 同一项目、同一动作模板、相似拍摄角度。
- 同一动作模板下的上一次记录。
- 同一动作模板下最近三次趋势。
- 同一动作阶段内的指标，如弓步落地阶段对弓步落地阶段。
- 同一拍摄质量等级或相邻质量等级的视频。

## 不允许比较

- 花剑弓步冲刺和实战比赛混比。
- 攀岩 lead 连续上攀和单个难点动作混比。
- 深蹲和跳跃落地混比。
- 拍摄角度差异过大时直接比较具体角度。
- 把 `部分可评分` 视频和 `可评分` 视频做精确数值差异判断。
- 把不同动作阶段混在一起比较，例如把弓步准备阶段膝角和落地阶段膝角直接比较。
- 把缺少质量摘要的旧 JSON 当作高置信度历史样本。

## 输出结构

历史对比应输出：

```markdown
## 八、历史对比

### 相对上一次
- 进步：
- 退步：
- 基本稳定：

### 最近三次趋势
- 趋势改善：
- 趋势变差：
- 波动较大：

### 下次复测重点
- <指标 1>
- <指标 2>
```

## 指标分层

### 可量化指标

来自姿态 JSON 或明确视频时间序列：

- 关节角度
- 动作周期时长
- 姿态稳定性变化
- 左右差异
- 关键阶段出现时间

### 半定量指标

由视频观察和姿态数据共同支持：

- 节奏是否更连贯
- 重心是否更稳定
- 动作是否减少多余预摆
- 攀岩停顿是否减少

### 不应比较的指标

- 无法从单机位可靠判断的真实 3D 距离。
- 没有统一机位时的绝对速度。
- 没有清晰脚部画面时的足压和发力点。
- 没有声音或上下文时的完整战术意图。

## 置信度

历史对比必须给出置信度：

- 高：同模板、同角度、动作周期足够、关键点完整。
- 中：同模板但角度或清晰度有差异。
- 低：只能比较大方向，不比较精确数值。

## 最小可比单元

历史对比的最小单元是：

```text
动作模板 + 动作阶段 + 指标 + 拍摄质量等级
```

例如：

- `花剑-弓步冲刺专项 / 前脚落地阶段 / 前膝角度 / 可评分`
- `攀岩-lead-连续上攀 / clipping 前站位 / 高屈肘停留 / 可评分`
- `体能-跳跃落地 / 初触地-缓冲阶段 / 膝踝对齐 / 可评分`

如果只有模板相同，但阶段或质量不一致，只能写趋势观察。

## 历史趋势写法

必须分成三类：

- `进步`：本次相对上次有明确证据改善。
- `退步`：本次相对上次有明确证据变差。
- `稳定`：无明显变化或证据不足以判定变化。

不允许写“整体有进步”而不说明哪个阶段、哪个指标、证据是什么。

当置信度低时，报告应写：

```text
由于本次和上次拍摄角度不同，以下对比只作为训练观察，不作为严格量化结论。
```
