# 视频质量前置分析

## 总原则

PoseAnalysis 必须先判断视频是否适合分析，再决定是否评分。质量不足时可以输出 `不可评分`，只给重新拍摄建议。

评分可信度优先于报告完整度。不能为了给出分数而过度推断。

## 质量结论

### 可评分

满足当前动作模板的核心技术判断条件。可以给综合评分、维度评分、训练建议和历史对比。

### 部分可评分

只满足部分维度判断条件。可以分析可靠维度，但不得对缺失维度给确定结论。一般不输出综合总分，或必须明确低置信度。

### 不可评分

视频不足以支撑技术评分。报告只输出：

- 不可评分原因
- 可以保留的低置信度观察
- 下次重拍建议

## 通用检查项

| 检查项 | 合格标准 | 失败影响 |
| --- | --- | --- |
| 主体完整性 | 关键动作阶段中头、躯干、髋、膝、踝或专项关键部位可见 | 关键关节缺失时不可评分 |
| 动作周期 | 至少 1 个完整动作周期；重复训练建议 3 次以上 | 周期不足时不做稳定性判断 |
| 清晰度 | 主体无严重运动模糊 | 快速动作角度和节奏不可信 |
| 光线 | 不过暗、不过曝 | 关键点检测不稳定 |
| 镜头稳定 | 无长时间晃动或频繁变焦 | 时间序列指标不可信 |
| 主体占比 | 运动员是主要主体，身体高度约占画面 35%-80% | 太小会降低关键点精度 |
| 遮挡 | 关键阶段无严重遮挡 | 被遮挡维度不可评分 |
| 角度 | 与动作模板要求匹配 | 错误角度只能部分分析 |

## 花剑专项拍摄门槛

### 弓步冲刺专项

推荐拍摄：

- 横屏。
- 镜头固定。
- 从侧面拍摄，尽量垂直于弓步前进方向。
- 起始准备、启动、前脚落地、触达/完成、回收都在画面内。
- 双脚、髋、膝、踝、躯干和持剑臂尽量完整可见。
- 快速动作建议 60 fps；至少 30 fps。

不可评分或降级情况：

- 前脚落地瞬间出画。
- 后腿被遮挡，无法判断蹬伸。
- 镜头从正前方或正后方拍摄，无法判断弓步深度。
- 只拍到上半身，无法判断步法。
- 只拍到结束姿势，没有启动和回收。

### 一对一教练课片段

推荐拍摄：

- 侧后方或侧前方固定机位。
- 能看到孩子、教练和双方距离变化。
- 尽量保留教练口令和动作上下文。

如果教练遮挡孩子关键动作，报告应优先分析节奏和距离，降低姿态角度评分。

### 实战比赛片段

推荐拍摄：

- 横屏固定机位。
- 尽量拍到整条交锋线和两名选手。
- 分析对象必须明确。

实战片段中，战术和时机判断通常比单项角度评分更可靠。遮挡或距离太远时，不给精确技术分。

## 攀岩专项拍摄门槛

推荐拍摄：

- 横屏或竖屏均可，但必须完整包含孩子、当前路线区域、手脚触点。
- 镜头稳定，避免跟拍时频繁丢失手脚。
- top rope/lead 连续上攀建议拍完整一段路线，不只拍最后一步。
- lead 分析 clipping 时，必须能看到绳、快挂、手部和身体位置。

不可评分或降级情况：

- 手脚触点经常出画。
- 绳索、保护员、墙面结构长期遮挡髋部或肩肘。
- 只拍到背部近景，无法判断脚法和重心。
- 镜头垂直角度过大，无法判断身体相对墙面的控制。
- 只拍到成功完成，没有前置准备和移动过程。

## 基础体能专项拍摄门槛

推荐拍摄：

- 每个动作单独拍。
- 镜头固定。
- 动作前后各保留 2 秒。
- 重复动作建议 3-5 次。

视角建议：

- 深蹲：侧面为主；如关注膝内扣，补充正面。
- 弓步/分腿蹲：侧面看髋膝踝和深度，正面看左右对称和膝轨迹。
- 俯卧撑：侧面看躯干和肩肘；斜前方可辅助看左右对称。
- 平板支撑/hollow hold：侧面。
- 跳跃落地：正面看膝踝对齐，侧面看髋膝缓冲。
- 单腿平衡/单腿下蹲准备：正面和侧面都重要。

不可评分或降级情况：

- 摄像机放在地面极低角度导致关节关系畸变。
- 身体部分长期出画。
- 只拍静态完成姿势，不拍动作过程。
- 地面或脚部不可见。

## 输出格式

前置质量分析应在报告开头输出：

```markdown
## 一、拍摄质量与可评分结论
- 结论：可评分 / 部分可评分 / 不可评分
- 置信度：高 / 中 / 低
- 主要依据：
  - <依据 1>
  - <依据 2>
- 受限制的判断：
  - <无法可靠判断的内容>
```

如果不可评分，后续报告应改为：

```markdown
## 二、不可评分原因
## 三、可保留观察
## 四、重新拍摄建议
```
