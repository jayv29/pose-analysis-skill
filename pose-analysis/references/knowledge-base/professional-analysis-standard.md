# 专业运动视频分析标准

## 目标

本文件定义 PoseAnalysis 的专业判断边界。目标是接近职业队/国家队分析团队的工作方式：先判断证据质量，再给技术结论；先分解动作阶段，再评分；先写可复核证据，再给训练处方。

这不是官方认证体系。报告必须诚实标注单机位视频、MediaPipe 姿态估计和拍摄角度带来的限制。

## 证据等级

### A 级证据：可量化、可复核

必须满足：

- 视频质量为 `可评分`。
- 关键动作阶段清楚。
- 相关关节或身体部位在关键阶段可见。
- 姿态 JSON 中有对应指标，或视频时间点能直接观察。

可用于：

- 维度评分。
- 历史同模板量化对比。
- 明确技术问题排序。

### B 级证据：半定量、可观察

满足：

- 视频能看清动作趋势，但角度、遮挡或帧率限制影响精确数值。
- 有部分姿态指标或多个时间点视觉证据支持。

可用于：

- 技术趋势判断。
- 训练建议。
- 低精度历史对比。

不得用于：

- 精确角度差异。
- 严格速度对比。
- 高置信度综合评分。

### C 级证据：低置信观察

满足：

- 画面能看出大致动作，但关键部位缺失或阶段不完整。

只能用于：

- 重拍建议。
- 需要教练现场复核的假设。

不得用于：

- 技术评分。
- 历史定量比较。
- 判定战术意图。

## 单机位视频边界

单机位 2D/弱 3D 姿态分析可以较好支持：

- 矢状面动作趋势：如弓步深度、深蹲深度、躯干前倾。
- 时间序列趋势：如动作是否连贯、停顿是否增加。
- 明显对称性问题：如落地膝内扣、单腿支撑骨盆掉落。
- 上肢大角度趋势：如攀岩长期屈肘、俯卧撑肩肘路径。

单机位分析不能可靠支持：

- 真实 3D 距离和速度。
- 足底压力、抓握力量、墙面反作用力。
- 细小旋转角度，如髋内旋、踝内翻。
- 被遮挡侧肢体的确定性判断。
- 无上下文比赛片段中的完整战术意图。

## 评分置信度

### 高置信度

- 质量门槛为 `可评分`。
- 动作模板明确。
- 机位与模板匹配。
- 同一动作至少 1 个完整周期；重复动作建议 3 次以上。
- 关键身体部位在关键阶段可见。

### 中置信度

- 质量门槛为 `部分可评分`。
- 只缺失少量维度。
- 可以给维度观察，但不建议给综合总分。

### 低置信度

- 质量门槛接近 `不可评分`。
- 只能输出拍摄建议和保守观察。

## 评分原则

综合评分不是动作漂亮程度，而是当前视频证据下的技术表现评分。

评分必须满足：

- 每个扣分点对应一个证据。
- 每个训练建议对应一个技术问题。
- 每个历史比较只和同模板比较。
- 儿童训练建议不使用成人最大强度逻辑。

## 结论优先级

最终报告的问题排序按以下顺序：

1. 影响专项表现的核心技术问题。
2. 影响动作可持续性和稳定性的基础问题。
3. 可通过一周训练改善的问题。
4. 需要长期追踪的问题。
5. 只需拍摄改善才能判断的问题。
