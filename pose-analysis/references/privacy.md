# 儿童隐私与脱敏规则

## 默认身份

报告默认使用匿名身份：

```text
运动员A
```

除非用户明确要求，报告不得写入儿童真实姓名、学校、俱乐部、家庭住址、联系方式或其他可识别身份的信息。

## 文件与报告命名

建议文件名不包含真实姓名：

```text
2026-05-24_花剑_弓步冲刺专项_A01.mov
```

不建议：

```text
2026-05-24_<真实姓名>_花剑_弓步.mov
```

## 报告措辞

允许：

- “本次前脚落地稳定性不足。”
- “后腿蹬伸完成度比上次下降。”
- “下次应重点追踪启动顺序。”

避免：

- “孩子协调性很差。”
- “没有天赋。”
- “心理素质差。”

## 数据处理边界

- 默认使用本机文件和本机生成报告。
- 不主动上传视频、截图或报告。
- 不把儿童视频用于其他数据集或模板样例。
- 引用历史记录时只引用同一匿名身份和动作模板。

## 医疗边界

PoseAnalysis 可以提示“建议教练或专业人士进一步观察”，但不做医疗诊断。

不得输出：

- 伤病诊断
- 康复处方
- 医疗风险定级
- 用药、治疗或复健替代建议
