# 输入规范

## 默认视频收件箱

第一版默认从 iCloud Drive 收件箱读取用户指定视频：

```text
~/Library/Mobile Documents/com~apple~CloudDocs/PoseAnalysis/Inbox
```

用户可以继续用 iPhone 拍摄，并通过“保存到文件”或快捷指令把视频放入该目录。Codex skill 只负责读取本地已同步文件，不直接访问 Photos Library。

## 支持格式

常用格式：

- `.mov`
- `.mp4`
- `.m4v`
- `.avi`

优先使用 iPhone 原始视频或未过度压缩的视频。被社交软件压缩过的视频可能会降低关键点识别质量。

## 命名规范

推荐文件名：

```text
YYYY-MM-DD_项目_动作模板_片段编号.mov
```

示例：

```text
2026-05-24_花剑_弓步冲刺专项_A01.mov
2026-05-24_花剑_一对一教练课_A01.mov
2026-05-24_花剑_实战比赛_A01.mov
2026-05-24_攀岩_top-rope_连续上攀_A01.mov
2026-05-24_攀岩_lead_连续上攀_A01.mov
2026-05-24_体能_深蹲_A01.mov
```

## 用户指令规范

如果文件名没有包含完整信息，用户应在 Codex 指令里提供：

- 视频位置或“iCloud Inbox 最新视频”
- 项目：花剑 / 攀岩 / 体能
- 动作模板
- 是否需要历史对比
- 需要重点关注的问题

示例：

```text
分析 iCloud Inbox 里最新视频。项目：花剑。动作模板：弓步冲刺专项。重点看后腿蹬伸和前脚落地稳定性，并和上一次同模板对比。
```

## 项目和动作模板

第一版不自动判断项目。必须由文件名或用户指令指定。

有效项目：

- `花剑`
- `攀岩`
- `体能`

有效动作模板以知识库文件为准：

- `knowledge-base/foil.md`
- `knowledge-base/climbing.md`
- `knowledge-base/fitness.md`

## 多人视频

如果视频中出现多名运动员，用户应明确分析对象，例如：

```text
分析右侧穿蓝色上衣的孩子。
```

如果无法稳定识别目标运动员，报告必须降级为 `部分可评分` 或 `不可评分`。
